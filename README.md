# WinFetch

WinFetch — это утилита для Windows, которая выводит информацию о системе в стиле Linux-программ `fastfetch` и `neofetch`. Программа показывает логотип в ASCII-арте и системные данные (ОС, процессор, память, диск, IP-адрес, GPU, пакеты и частоту обновления экрана), автоматически окрашивая текст в системный акцентный цвет Windows.

Утилита состоит из двух частей:
1. Python-скрипт (`winfetch.py`) — собирает и выводит основную информацию.
2. PowerShell-скрипт (`winfetch.ps1`) — добавляет дополнительные фишки (количество пакетов, частоту обновления и палитру цветов).

Python-скрипт сам вызывает PowerShell-скрипт, поэтому вам достаточно запустить только его.

## Особенности

- Автоматическое определение системного акцентного цвета Windows.
- Определение CPU, GPU, памяти, диска, IP-адреса, темы оформления и разрешения экрана.
- Дополнительные данные: количество установленных пакетов через `winget` и частота обновления экрана.
- Палитра цветов внизу вывода.
- Работает как из исходного кода, так и в виде собранного `.exe`.

## Требования

- Python 3.8+
- Библиотека `psutil`
- PowerShell (встроен в Windows)
- `winget` (для подсчёта пакетов, опционально)
- PyInstaller (для сборки `.exe`)

## Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
pip install psutil pyinstaller
```

Если вы планируете выкладывать проект на GitHub, создайте файл `requirements.txt`:

```
psutil>=5.9.0
pyinstaller>=6.0.0
```

## Запуск из исходного кода

Просто запустите Python-скрипт:

```bash
python winfetch.py
```

Скрипт выведет основную информацию и автоматически вызовет `winfetch.ps1`, который допишет пакеты, частоту обновления и палитру.

## Сборка в `.exe`

Чтобы собрать всё в один исполняемый файл, выполните:

```bash
pyinstaller --onefile --console --name winfetch --add-data "winfetch.ps1;." winfetch.py
```

После сборки в папке `dist` появится `winfetch.exe`. Его можно переместить в любую папку и запускать оттуда.

Важно: файл `winfetch.ps1` вшивается в `.exe` через `--add-data`, поэтому при запуске он извлекается во временную папку и вызывается автоматически.

## Добавление в PATH (запуск из любой папки)

Чтобы запускать утилиту командой `winfetch` из любого места:

1. Переместите `winfetch.exe` в удобную папку (например, `C:\Tools\`).
2. Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
3. Перейдите в «Дополнительно» → «Переменные среды».
4. В блоке «Переменные среды пользователя» выберите переменную `Path` и нажмите «Изменить».
5. Нажмите «Создать» и укажите путь к папке с `winfetch.exe` (именно папку, не файл).
6. Нажмите ОК во всех окнах и перезапустите терминал.

Теперь команда `winfetch` будет доступна из любой папки.

## Решение проблем

### Программа зависает при запуске

В ранних версиях использовалась библиотека `py-cpuinfo`, которая могла конфликтовать с Windows 11. В текущей версии она заменена на вызов PowerShell (`Get-CimInstance Win32_Processor`), что работает быстро и стабильно.

### Команда `winfetch` не распознаётся

Убедитесь, что в `Path` добавлен путь именно к папке, а не к файлу. После изменения `Path` перезапустите терминал.

### Цвета не отображаются (выводятся как `e[96m`)

Это происходит в Windows PowerShell 5.1, который не понимает последовательность `` `e ``. В текущей версии `winfetch.ps1` используется явный символ ESC (`[char]27`), поэтому проблема решена.

### Ошибка «файл не имеет цифровой подписи»

Запустите PowerShell-скрипт с обходом политики:

```powershell
powershell -ExecutionPolicy Bypass -File .\winfetch.ps1
```

Или запустите `winfetch.bat`, который делает это автоматически.
