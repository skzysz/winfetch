# WinFetch 🐧➡️🪟

**WinFetch** — это легковесная утилита для Windows, написанная на Python, которая выводит информацию о системе в стиле популярной Linux-программы `fastfetch` (или `neofetch`). 

Программа показывает логотип в ASCII-арте и выводит ключевые характеристики вашего ПК (ОС, процессор, память, диск, IP-адрес и т.д.), автоматически окрашивая текст в **системный акцентный цвет Windows**.

## ✨ Особенности
*   **Цветовая адаптация**: Цвет заголовков и логотипа автоматически подстраивается под ваш акцентный цвет Windows (Настройки → Персонализация → Цвета).
*   **Работа из любой папки**: После установки утилиту можно вызывать простой командой `winfetch` из любого терминала (CMD или PowerShell).
*   **Быстрый сбор данных**: Использует библиотеку `psutil` для мгновенного получения информации о памяти и дисках без зависаний.
*   **Не требует Python**: Собирается в один независимый `.exe` файл.

## 🛠️ Требования
Для запуска и сборки вам понадобится:
*   Python 3.8+
*   Установленные библиотеки (см. ниже)

## 🚀 Установка и сборка

### 1. Клонирование и установка зависимостей
Скачайте файл `winfetch.py` в любую папку (например, `C:\projects\winfetch\`). Откройте терминал в этой папке и установите необходимые библиотеки:

```bash
pip install psutil pyinstaller
```

### 2. Сборка в `.exe`
Чтобы превратить скрипт в полноценную утилиту, выполните команду:

```bash
pyinstaller --onefile --console --name winfetch winfetch.py
```
*   `--onefile` — собирает всё в один `.exe`.
*   `--console` — оставляет окно терминала для вывода текста.

После завершения сборки в папке появится директория `dist`, внутри которой будет лежать файл **`winfetch.exe`**.

### 3. Добавление в PATH (Запуск из любой папки)
Чтобы не писать полный путь к файлу каждый раз, добавьте папку с `winfetch.exe` в системные переменные:

1. Переместите `winfetch.exe` в удобную для вас папку (например, `C:\Tools\`).
2. Нажмите `Win + R`, введите `sysdm.cpl` и нажмите Enter.
3. Перейдите в **«Дополнительно»** → **«Переменные среды»**.
4. В блоке **«Переменные среды пользователя»** выберите переменную **`Path`** и нажмите **«Изменить»**.
5. Нажмите **«Создать»** и укажите путь к папке, где лежит `winfetch.exe` (именно папку, а не сам файл!).
6. Нажмите **ОК** во всех окнах и **перезапустите терминал**.

Теперь в любом месте вы можете просто написать:
```bash
winfetch
```

## 💻 Использование
Просто откройте CMD или PowerShell и введите:
```bash
winfetch
```

## ❓ Решение проблем

**1. Программа зависает или компьютер начинает шуметь при запуске.**
*   **Причина**: Библиотека `py-cpuinfo` иногда конфликтует с новыми версиями Windows 11 при опросе процессора через WMI.
*   **Решение**: В актуальной версии скрипта эта библиотека заменена на безопасный метод `platform.processor()`. Убедитесь, что вы используете последнюю версию кода из этого репозитория, и пересоберите `.exe`. Также добавлен таймаут для проверки IP-адреса.

**2. Команда `winfetch` не распознается.**
*   **Решение**: Убедитесь, что вы добавили в `Path` именно **путь к папке**, а не путь к файлу (не должно быть `\winfetch.exe` на конце). После изменения `Path` **обязательно** закройте и откройте терминал заново.

**3. Цвета не такие, как в системе.**
*   Утилита берет цвет из реестра `HKEY_CURRENT_USER\Software\Microsoft\Windows\DWM` (параметр `ColorizationColor`). Если вы недавно меняли тему, перезапустите проводник или сам терминал, чтобы цвет применился.
